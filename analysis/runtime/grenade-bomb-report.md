# Revolver, grenade and C4 native contracts

Default skin names: Revolver `revolver`, Grenade `grenade`, Smoke `smoke`, Flashbang `flash`, Molotov `molotov`, Bomb/C4 `bomb`. `Grenade` only declares Shoot, CenterForInspect and its constructor; there is no SetSkin override. Shooter.SetWeapon's inherited Weapon.SetSkin path therefore constructs `https://kour.io/content/stream/weapon-skins/texture/{defaultSkinName}.png` (plus loader size query). These are normal UnityWebRequestTexture PNG inputs. WorldBomb independently declares LoadMyMaterialTexture.texturePath=`weapon-skins/texture/bomb` per the asset agent; it resolves to the same bomb PNG. Mesh URLs are separate StreamingAssets inputs.

BuyMenuCanvas.BuyWeapon is table18164/function74677, `(canvas,onSlotIndex,BuyMenuItemPointer,MethodInfo0)->void`. It validates and deducts cost, then calls Shooter.GiveWeapon. GiveWeapon is table20677/function74292, `(shooter,onLocalSlotIndex,weaponIndex,ammoMinus1,MethodInfo0)->void`. It updates the inventory and invokes SetWeapon with force=true. Shooter.SetWeapon is table20724/function74291, `(shooter,localSlot,forceBool,MethodInfo0)->void`. Use actual BuyMenuItem objects and their intended slots to exercise original purchasing; GiveWeapon alone bypasses pricing.

For C4, use the original round setup: select T, then invoke native StartRound once. StartRound selects a random T actor as holder (the only local T actor is selected), and BuyPhase.OnStateChanged compares holder actor with local actor before calling Shooter.SetBomb. SetBomb is table20676/function74290, `(shooter,giveBombBool,isPlantingBool,MethodInfo0)->void`. It manages inventory and network state; the native bomb weapon index is31. When giveBomb or isPlanting is true, it invokes SetWeapon(localSlot2,force=true) at23584104..23584110. Raw ownership/inventory writes are unnecessary.

Native excerpts are retained in grenade-bomb-static.json. Metadata is recovered in gameplay.json and retained REA evidence; native WASM instructions are decoded by the local scalar parser. Visual success and actual planting must be verified in the parent's local runtime.

WorldGrenade.Init (function76886) also prefixes its skin name with weapon-skins/texture/ (literal at24516783; String.Concat24516795), then calls TextureLoader.GetTexture2DOf at24517082. Its callback function76897 assigns the downloaded image to Renderer.material.mainTexture at24522712 and another material at24522734. Thus the same four grenade PNGs cover thrown-projectile texture paths as well as equipped weapons. This is static path/callback evidence, not an observed throw or explosion.

WorldBomb's force=false texture request is skipped only when PlatformDetector.isMobileWeb=true. If this flag is true and force is false, it calls the supplied callback(null) and skips downloading at24405228..24405257. Desktop requests proceed normally; gameType1 has no role in this early gate. The native held-weapon default-skin call supplies force=true and bypasses it. A read-only flag probe is `HEAPU8[read32(read32(6908736)+92)+1]`.
